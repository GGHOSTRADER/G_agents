Software architecture supported by Agentic help

---- Contract ----
Invariant : State was must happen / be true
Failure Mode : Map the errors that will happen if invariant is broken
Acceptance Criteria : Create the tests that should happen for the code to make sure invariant and failure mode are working

---- Clean Architectural ----
Domain: “I compute features”  --> My business logic pure functions like modslope5
Application: “I decide when to compute” --> Coordinates Domain, Application and Infrastructure
Infrastructure: "I hold the tech that communicates with the outside world" --> My outside word like redis 
	Adapter: (border of infra, before Domain) “I fetch/emit data” --> My translator between infrastructure and domain, xread and parser

---- Code macro view ----
Runtime chain = who calls whom in a sequential order in a specific execution
	Several Runtime chains can coexist in one code
Dependency graph = who needs whom to exist
Data flow = Shows data state and transformations through the runtime

Real Example
modSlope5
----
- Directory Tree: Not needed
- Code Dependencies: None from previous layers / Functions
- Input :  5 window Deque[Bar] with required fields: high, low, close, bar_num
- Input data type: Deque window
- Input Origin: Provided by Upstream BarWindow; already cast to numeric types.
- Output : scalar
- Output Data Type: Float
- Style: Pure Function , Clean architecture , No side effect
- Location: Not in boundary, This function enforces minimal local preconditions (length + continuity).
- Description : Slope of the last 5 bars
- Side effects: None
- Calculation : (bars[-1].high + bars[-1].low + bars[-1].close)/3 - (bars[-5].high + bars[-5].low + bars[-5].close)/3
- invariants :   
	Bars in window : E_LEN = len(bars)==5 , 
	Bar continuinity : E_GAP = all(bars[i].bar_num == bars[i-1].bar_num + 1 for i in range(1, 5))
	Slope result = Returns Python float
- Failure Mode: 
	len(bars) != 5 Raise BarWindowError("E_LEN: expected 5 bars")
	Continuity check fails Raise BarWindowError("E_GAP: non-consecutive bar_num") 
- Acceptance criteria: 
	Posite tests
		Assert result is python float 
		known fixture returns expected numeric value
	Negative Tests
		Raise BarWindowError if continuinity break of the 5 bars window
		Raise BarWindowError with code E_LEN when len(bars) != 5.
	Non-functional
		No mutation, deterministic
- Assumptions / Guarantees : 
	Data casted and validated by Upstream BarWindow Contract , 
	High, low and Close they all been revised. 
- Data dependency: Upstream BarWindow / Bar ingestion
